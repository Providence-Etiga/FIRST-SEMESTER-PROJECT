CHATTER Landing Page

About the Project

CHATTER is a landing page for a blogging platform that connects writers and readers. The idea behind the platform is to create a space where people can share their thoughts, discover interesting content, interact with other users and connect with people who have similar interests.

This project is part of my frontend development learning journey. I built the landing page using a Figma design as my reference, trying to recreate the design as closely as possible.

What the Website Contains

The landing page is made up of different sections:

- Navigation Bar: Contains the logo, navigation links, login and sign-up buttons.
- Hero Section: Introduces the platform and welcomes visitors to CHATTER.
- About Chatter: Gives a brief description of the platform and what it aims to achieve.
- Why You Should Join Chatter: Highlights some of the benefits of using the platform, including analytics, social interactions and content creation.
- Testimonial: Features a user's experience with the platform.
- Call to Action: Encourages visitors to join the CHATTER community.
- Footer: Contains useful links, support information and blog resources.

Technologies Used

I used the following technologies to build this project:

- HTML5
- CSS3
- Google Fonts (DM Sans)

No JavaScript was used in this project. The focus was mainly on HTML structure and CSS styling

What I Learned

Working on this project gave me the opportunity to practise and improve my understanding of:

- Writing structured HTML.
- Styling webpages with CSS.
- Using Flexbox and CSS Grid to arrange elements.
- Working with images and icons.
- Understanding CSS positioning.
- Using media queries to make websites responsive.
- Translating a Figma design into an actual webpage.
